শ্বশুরের রাস্তা — Android Studio প্রজেক্ট (v0.1)

গুরুত্বপূর্ণ: এটি APK ফাইল নয়; এটি APK তৈরি করার জন্য Android Studio প্রজেক্ট।
এই চ্যাটের পরিবেশে Android SDK/Gradle build চালিয়ে ইনস্টলযোগ্য APK তৈরি ও পরীক্ষা করা সম্ভব হয়নি।

APK বানানোর নিয়ম:
1. কম্পিউটারে Android Studio ইনস্টল করুন।
2. এই ZIP ফাইল Extract করুন।
3. Android Studio → Open → Extract করা ShoshurerRasta_Android_Project ফোল্ডার নির্বাচন করুন।
4. Gradle sync শেষ হলে Build → Build Bundle(s) / APK(s) → Build APK(s) চাপুন।
5. APK সাধারণত app/build/outputs/apk/debug/app-debug.apk এ তৈরি হবে।
6. ফোনে কপি করে ইনস্টল করুন। ফোনে “Install unknown apps” অনুমতি চাইতে পারে।

অ্যাপটি ইন্টারনেট permission চায় না; গেমের HTML assets-এর মধ্যেই আছে।
